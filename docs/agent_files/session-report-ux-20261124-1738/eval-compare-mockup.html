Per-line agreement

Line by line: did the combo give the same code as the human on the same line?

Precision = when the combo says SR, how often the human agrees (combo says SR 10 times, human agrees on 8: 0.80). Recall = of the human's SR lines, how many the combo found (human has 10, combo finds 7: 0.70). F1 = one blended number; it drops if either of the other two is low. Each cell shows precision / recall / F1.
