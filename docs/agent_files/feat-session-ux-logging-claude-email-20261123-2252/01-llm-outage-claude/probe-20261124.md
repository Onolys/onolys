**Action required for Gemini:** restore the staging Google AI Studio project's prepayment balance before testing Gemini rollback or expecting `oneshot` calls to succeed. Switching provider/model alone does not repair Gemini billing.

The initial probe revealed deferred LiteLLM debug logging after the direct call returned. The probe now mutes LiteLLM loggers after the call as well as discarding debug output during it; a regression test covers delayed logging. The observed deferred lines contained only callback metadata, no credentials.
