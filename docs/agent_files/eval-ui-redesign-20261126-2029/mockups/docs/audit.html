Writeup audit: Eval run + compare pages

Format: section header, then what it should contain. Cuts and merges are marked. Source: eval/web/src (Runs.tsx, RunStatus.tsx, compare/*).

Run page

  • Title: "Run - <run name>". Dash required. Description (if any) as muted line under it. Cut "Run <name or id>" form.
  • Run summary card. Run ID (copyable), Open logs link, action buttons (Config, Compare, Rerun, Cancel). Replaces the loose buttons and "Rerun with different engines/presets" (shorten to "Rerun...").
  • Status chips. One chip per state: overall status, done of total, running, queued, failed, cancelled (zero counts muted). Replaces the plain "running · 1/3 runs done · ..." line. Plus a progress bar.
  • Usage stats. Input tokens, output tokens, est. cost, started/elapsed as small stat tiles. Muted note: "Cost is an estimate. Speech-to-text is not included." Unpriced units listed in the cost tile, not in the sentence.
  • Alerts strip. Merge: provider skipped, provider busy/waiting, cancel-requested note, partial badge, run-level error. Each = icon + one sentence. Hidden when empty.
  • Unit progress. Header + ONE line: "One unit = session x engine x model/tier/effort x attempt. Human reference runs once." Cut the current multi-sentence caption and the duplicated "N/M runs done" next to the heading (already in chips).
  • Unit table. Columns: Session, Engine, Model, Tier, Effort, Attempt, Status (chip), Stage, Result. Search + status filter above. Muted footnote: truncation/sort/error-click hints.
  • Result cell. Done: "View JSON" (no id). Failed: red error-code badge, opens error popup. Running: mini progress. Skipped: "n/a" + reason.

Compare: shared header (all tabs)

  • Title: "Compare - <run name>" with Back to run link. Partial badge when cancelled/partial.
  • Summary cards. Sessions (n, attempts, combos); Human labels (chips: counts / globals covered); Coverage (one chip per session, "paired x of y", amber when incomplete); Excluded (failed combos with reason). Replaces the jumbled "Human labels... gi: paired 0 of 1 persuade: paired 0 of 1... Coverage" text.
  • Tabs. Overview, Deep dive, More analysis, Line view.
  • Combo legend. Letter tag + model + engine/tier/effort; failed combos flagged. Shown once, not repeated per tab.

Overview

  • Verdict. One or two sentences with n tags. Excluded-combo note in muted small text.
  • Leaderboard. Sortable table (arrow indicators on plain headers). Best marked with star + "best"; failed combos excluded from best and shaded red. Cut: per-column definitions merged into one muted note.
  • Leaderboard notes. One muted block: column meanings, "Sessions have equal weight; repeats averaged first", "Time may read short for retried units". Currently loose plain sentences.
  • Metric heatmap. Rows grouped (counts, globals, ratios). Big = avg miss, small = signed bias. Legend row replaces the 4 separate legend paragraphs and "How to read".

Deep dive

  • Compare combos. Combo toggle chips + "paired x of y". Cut "Compare combos" fieldset legend look.
  • Globals. One card per global: dot plot, legend, avg miss / within +-1 chips; separate card with same / off-by-1 / off-by-2+ bars. Captions = one sentence each (replace long "How to read").
  • Counts per code. Small-multiple cards: bars Human vs combos + bias chip ("under-counts 21%").
  • Per-line agreement. P/R/F1 table + confusion grid (switchable combo). If no line-level output: one message naming the missing side.
  • Reasoning roll-up. Per code, accordion; Human count + combo snippets. One muted note ("loads on request, withheld if empty").
  • Data tables. Each chart's table twin sits behind a "Show data" disclosure, not inline.

More analysis

  • Cost vs accuracy. Scatter + frontier line. Unpriced/failed combos listed under it.
  • Error vs interview length. Scatter/lines by combo, Turns/Words toggle.
  • Human-vs-human baseline. Card with the n/a text (needs a second coder).
  • Reliability. Table: repeat agreement, fails, time per combo.
  • Head-to-head. Matrix "row closer than column on N of M"; ties note.
  • Interviews by combo. Session x combo grid, count error + repeats, session links to Line view.

Line view

  • Filters. Session picker, only-disagreements, code, combo; count of differing lines chip.
  • Transcript lanes. # / speaker chip / line text / Human / one lane per combo; disagreements amber with warning mark. One muted note (blank human = no label; text verbatim). Cut the long "How to read".
  • Global ratings (session). Table of human vs combo rating chips (green exact, amber off 1, red off 2+); reasoning behind disclosure.
  • Line popup. Line text, human code, each combo code + rationale, "k of r repeats agree".

Popups

  • Config. Key facts as tiles (dataset, sessions, attempts, goal, language, versions), combo list with tags, raw JSON behind disclosure + Copy. Used for every "Config" entry point (run page, history, compare).
  • Error. Title "Unit <id> failed", code/stage/HTTP/retryable chips, plain-language message, full error block + Copy, one-line fix hint.
  • Unit output. Title "Unit output", unit id shown here (not on the button), JSON.
