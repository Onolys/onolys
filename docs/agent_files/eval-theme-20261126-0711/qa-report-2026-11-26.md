## Bugs / findings (no product code changed)

1. Cosmetic, pre-existing (RunStatus.tsx PartialBadge not touched by branch): in History, a Partial run's Status badge renders as a circle with text clipped/overflowing the pill in the narrow column. Repro: run with status `partial`, `cancelled_at`, `provider_skips` shown in History at 1280px. Evidence: qa-history-light.png, qa-history-dark.png (bottom row). Cause: Badge `rounded-full` + `whitespace-normal` wrapping into several lines.
2. Minor: sessions slider resets to all sessions when toggling Dataset -> Upload -> Dataset (set 5 of 12, toggle, payload had 12 sessions). Probably intended (mode change resets), flag only.
3. Minor spacing: on New Run, the "skipped: ..." list sits tight against the Start run button (qa-newrun-skipped-dark.png).
4. Minor: tab links preserve unrelated query params (404 at `/foo/bar?x=1` then New Run goes to `/?x=1`). Harmless.
5. Footer differs from prod by design (no Privacy/Terms/Contact row, notices only); header height, nav centring (x=640), avatar, colours and content width match prod (qa-prod-shell-*.png vs qa-shell-newrun-top-*.png).
6. Console: one `404` resource error on first load in the light run (not on later loads; no failed API responses recorded; likely favicon). No other console errors or warnings in any flow.
